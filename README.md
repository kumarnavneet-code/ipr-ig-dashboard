# IPR — IG dashboard

This repository contains only the generated public dashboard for the IG version of IPR, plus its current public feed and schemas. It is maintained separately from earlier IPO Radar versions.

The official-source collector, extraction code, configuration, private evidence, tests and project documents are maintained in a separate private IG repository. They are not part of this public artifact.

IPO research can be partial or stale; observation timestamps and unavailable fields remain visible. Repository upload is not verification of IPO facts or a live-server deployment.

For a future static web server, deploy this repository's dashboard files to a dedicated IG web root. Do not copy the earlier IPO Radar repositories, local prototypes or private source documents. Public assets must pass the private IG project's dashboard audit before publication.

Live IG website: https://kumarnavneet-code.github.io/ipr-ig-dashboard/

This is the active IG repository target. Earlier IPO Radar repositories are being retained separately as backups; migration state is recorded in the private IG project.
